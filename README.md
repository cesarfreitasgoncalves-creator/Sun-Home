# Nota 10 — Escola de Clicker

Um jogo clicker escolar: faça exercícios para ganhar pontos, compre melhorias e avance por 50 notas, de F até SXXXXX. O progresso fica salvo neste navegador.

## Como jogar

Abra `index.html` em um navegador. Clique em **Fazer exercícios** para ganhar pontos; use-os para comprar a caneta turbinada (mais pontos por clique) e a luminária (pontos automáticos). A opção **Recomeçar** apaga o progresso após confirmação.

As fontes e a imagem decorativa são carregadas do Google Fonts e do Unsplash, então precisam de conexão com a internet.
